About

I build the layer your business actually runs on

I'm a software engineer with 5+ years building enterprise ERP, CRM, and eCommerce platforms end to end. My work sits in backend architecture: designing REST APIs that downstream clients can depend on, modeling data in both relational and document stores, and making queries and caches fast enough that the product feels instant under real load.

On a production ERP I cut database query time by 80% by eliminating N+1 access patterns, adding composite indexes on high-cardinality lookup columns, and introducing a Redis caching layer for hot reads. I've designed role-based access control for multi-tenant systems, containerized services with Docker on AWS EC2, and mentored junior engineers through code review and architecture standards. I work across Node.js, Laravel, React, and Next.js.
